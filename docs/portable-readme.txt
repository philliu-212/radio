Radio Portable Lite — Windows x64

解壓縮整個資料夾，雙擊 RadioMini.exe 即可開啟。
不用安裝本程式、不需要 mpv／FFmpeg，也不需要 SDK 或命令列。
請保留資料夾內全部檔案，不要只複製 RadioMini.exe。

需求：
- Windows 10 2004／Windows 11 x64，具備 Windows 媒體元件。
- Microsoft .NET 8 Desktop Runtime（x64），不是只有一般 .NET Runtime。
  缺少 runtime 時，Windows/.NET 啟動器會提示；本程式不會自行安裝。
- 可連接電台官方來源的網路。

這是依賴系統 runtime 的輕量 portable 包，不是內含整套 runtime 的獨立包。
「免安裝本程式」不代表所有電腦都完全不需要準備環境。

操作：
- 用 + 管理收藏電台；點選電台立即開播／切台。
- 播放中按方形停止；再點電台或按播放可重新開播。
- 我的電台按成功播放次數排列，每頁五台，可用細捲動條／滾輪／鍵盤找台。
- 音量滑桿可直接點擊或拖曳，並記住上次音量。
- 「停止」會斷開播放來源；重新播放回到直播。
- 縮小收進系統匣並繼續播放，雙擊系統匣圖示可還原。
- 關閉視窗會停止播放並退出。
- 有正式新版時右上角顯示下載箭頭；點擊後下載同類型 Lite 包、驗證並重啟，保留設定。下載期間繼續播放。
- 啟動及每小時背景檢查 GitHub Release；更新需要可寫資料夾及 Windows PowerShell。失敗可重試或手動下載，記錄位於 %TEMP%/RadioMini-update-*/result.txt。

極簡橫向介面，支援深／淺色切換。啟動播放策略等操作以該版本的專案 README／Release Notes 為準。
主題、音量、收藏與播放次數保存在同資料夾的 radio.settings.json；唯讀資料夾則僅當次有效。
有官方資料時顯示節目／DJ 或預告歌曲；縮到系統匣後停止額外查詢。
