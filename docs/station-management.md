# 電台管理擴充（以 v0.3.6 為基礎）

## UI 與來源

- 沿用原生 WinForms、StationListBox、PlayerButton 與原有深／淺色配色。不更換音訊後端或 metadata provider。
- 主視窗 554 × 271 DIP：僅增加搜尋列所需的 38 DIP，維持欄寬比例、字級、31 DIP 可見電台列（37 DIP 含間隔），以及原有標題列／控制功能。
- 主畫面搜尋列為 30 DIP pill，放大鏡在內，外側 + 間距 12 DIP。搜尋只重建顯示資料，不觸發選台播放。
- 首次尚未完成設定且 0 台時直接開啟管理；空清單仍可按 ✓ 完成，回到只有中央 + 的主畫面。點 + 可再次進入管理；完成設定後重新啟動不重複強制開啟。
- 管理視窗空白區域與分類圖示可拖曳移動，不增加文字標題列；搜尋、清單、捲動與按鈕不觸發拖曳。視窗採深色 12 DIP 圓角，不繪製外框線。
- 四周 14 DIP 由視窗本身繪製，子元件完整避開圓角，不再使用多層圓角裁切。主畫面及管理清單選取僅顯示底色，不繪製虛線焦點框；鍵盤選台照常運作。
- 管理視窗為 690 × 293 DIP owned modal，主畫面留在背景。無文字標題／數量／手動排序；分類向量圖示獨立於 26 DIP pill，間距 9 DIP。pill 外右側間隔 6 DIP 放置 34 DIP 地球篩選按鈕，地球 14 DIP、箭頭 8 DIP，垂直置中；整列右側預留原有捲動條空間。中間四顆 30 × 30 DIP 圓角框線箭頭：上方 ›／‹ 批次加入／移除選取電台，下方 »／« 加入／移除全部搜尋結果；每組相隔 8 DIP，兩組相隔 18 DIP。可用時帶低彩度薄荷綠底，操作說明僅顯示於 Tooltip。✓ 為 26 × 26 DIP，空清單也可完成。
- 目錄優先沿用 `Radio.Core/stations.json` 的 7 台真實電台；可加入與已加入資料分離，`StationLibrary` 可接收擴充目錄。此次不接 Radio Browser API，避免引入未驗證串流與 metadata；未要求手動 URL。
- 移除正在播放的台時，在完成管理後停止並釋放來源；其餘管理或搜尋操作不停止播放。
- 主標題、原生視窗與工作列名稱只顯示 Radio Mini；版號僅保留在品牌標題懸浮提示及系統匣版本資訊項目，不加進系統匣 tooltip。無頻率電台標記為 WEB，RFI Monde 名稱不附語言括號。
- 程式顯示時，自動選取並播放最後一次成功收聽的收藏；沒有紀錄、紀錄指向已移除電台或首次啟動時，才回到成功播放次數最高的一台，同分沿用原順序，全零播放第一台。成功進入 `Playing` 才更新紀錄，失敗不覆寫。先套用已保存音量與播放器靜音狀態，0 台不嘗試播放。失敗保留重試入口，不跳台循環；最小化／隱藏後還原及管理頁加入不觸發啟動播放。`--no-autoplay` 可供診斷關閉此行為，UI probe 明確停用啟動播放。
- 狀態卡片的文字、控制項與空白均可懸浮滾輪調音量，不需聚焦，每格 2%，支援部分滾輪累積與 0–100 邊界，處理一次後攔截原生重複調整。只調播放器音量並保存，不解除靜音、不影響清單捲動或其他視窗；modal 管理期間不調整背景卡片。結束時移除訊息篩選器。
- 卡片內僅保留音量（初始即顯示正確百分比）與官網 Tooltip；電台名、狀態、播放／靜音與 metadata 不再顯示，包括被省略文字的 WinForms 自動提示。保留省略號、可見狀態及 AccessibleName；標題版號與管理頁的提示不變。

## 播放語言篩選

- 左右各自保存 `AvailableStationsLanguageFilter`／`MyStationsLanguageFilter` 的 UI 狀態，預設全部語言；只影響該側可見結果，不改收藏、播放或統計，不在主畫面增加篩選按鈕。關閉管理視窗後不持久化篩選。
- 共用一個約 150 DIP 深色浮動選單：全部語言、中文、English、Français；當前項目薄荷綠底色／文字，勾在右側。點選立即更新並關閉；點外部關閉，同時最多一個選單。非全部時地球變薄荷綠並顯示 5 DIP 小圓點，Tooltip 顯示目前語言，不在搜尋列顯示語言名稱。
- `Station.Languages` 為可選標準語言代碼陣列，如 `["zh", "en"]`，可容納未來語言。缺少、null、空陣列或尚未列入選單的語言仍在全部中顯示；不依名稱或國家推斷、不預設未知為中／英文。新增語言只需擴充選項資料與目錄資料，不需重寫篩選邏輯。
- 本機編輯目錄明確標記六個既有台灣電台主要節目語言 `zh`、RFI Monde 官方法文 Monde feed 為 `fr`；此欄位不是逐曲歌詞語言偵測。未增加未驗證電台，內建目前無英文專台；英文與多語行為由離線 fixture 驗證。未使用 Radio Browser API；未來若接入應優先採其語言資料，缺失維持未知。
- 文字與語言以 AND 篩選；名稱／顯示名稱／頻率搜尋保持大小寫不敏感，使用 Unicode 比對並忽略重音（`ecoute` 可找到 `Écoute`）。搜尋及篩選不改底層資料順序。
- 單／雙箭頭仍只搬移選取／可見結果。若任一搬移項目不符合目標的文字或語言條件，只清除不符合的條件，讓新項目可見；相容條件保留，來源條件不變。搜尋或語言改變後只保留仍可見的選取。

## 保存與相容性

管理視窗兩邊直接點擊即可選取／取消選取多台，無需按住 Ctrl；另支援 Ctrl+A 全選目前搜尋結果。單箭頭處理選取項目，雙箭頭處理該側所有搜尋結果，搜尋空白時即全部電台。隱藏項目不會被誤加入／移除；左右搜尋更新保留仍可見的已選取項目。主播放器維持單選及原本切台行為。

`radio.settings.json` 繼續使用原本 portable 同目錄、暫存檔後覆寫方式。schema 2 新增：

- `MyStationIds`：依穩定 ID 保存順序；缺少或空陣列表示 0 台。
- `PlayCounts`：電台 ID 對應累積成功播放次數（64 位元整數）。移除後不刪統計，重新加入仍保留。
- `LastStationId`：最後一次真正進入 `Playing` 的電台 ID；啟動自動播放優先使用，缺少或已不在收藏時回到 `PlayCounts` 排序。
- `StationSetupCompleted`：是否已完成首次管理，避免 0 台每次啟動重複彈窗；缺少時視為尚未完成。
- schema 1 仍可讀取，保留 Theme／Volume；舊版沒有使用者選台資料，不虛構已加入清單或次數。
- 加入／移除、首次成功播放、偏好調整及結束時保存。唯讀目錄沿用既有行為：當次可操作，但不能持久化；不改寫 AppData／registry。

只有啟動自動播放或使用者發起的新播放工作階段首次收到真正的 `Playing` 事件才計數。解析失敗、Opening、Buffering、Failed、管理選取與搜尋均不計數；同次工作階段再次收到 Playing 不重複計數。每次成功計數立即穩定降冪排序（同分保留原順序），同步主清單及開啟中的管理頁，以電台 ID 保留選取，不重新播放。加入時也套用既有次數排序；管理頁完成後不自動選取第一台或播放，與程序首次啟動的自動播放分開處理。

## 驗證

```powershell
dotnet build src/Radio.Windows -c Release
dotnet run --project tests/Radio.Core.Tests -c Release
dotnet run --project tests/Radio.Windows.Tests -c Release -- --ui
dotnet run --project tests/Radio.Windows.Tests -c Release -- --system
```

UI 測試使用假音訊／metadata，測試設定使用獨立 fixtures，不修改使用者設定。涵蓋搜尋不切台、雙清單轉移／去重／獨立搜尋、modal 所有權、首次與已設定的 0 台流程、即時穩定排序、成功／失敗／重複事件計數、設定重新讀取，以及原有音量／metadata／系統匣／DPI 回歸。另驗證獨立中英法／多語／未知及未來語言、重音 Unicode AND 搜尋、框外地球／狀態點、浮動選單、隱藏選取清除與目標篩選適度重設。

截圖保存在 `artifacts/station-*.png`。離線測試與模擬 DPI 訊息不代表各電台即時線上可用或實體多螢幕人工驗收；官方串流及節目資訊可能受來源變更與地區限制影響。

### 高 DPI 初始配置回歸（#55）

電台管理視窗必須在完整控制項樹建立後才恢復配置。若建構期間提前消耗 96-DPI 自動縮放基準，高 DPI 下搜尋列仍可能只有 26 像素，而圖示／文字已按 DPI 放大。修正使用成對的 `SuspendLayout`／`ResumeLayout`，不改既有邏輯尺寸與箭頭行為。

可單獨執行 `dotnet run --project tests/Radio.Windows.Tests -c Release -- --dpi-ui`（也包含於 `--ui`）。測試在同步、尚未建立原生視窗的建構期間，暫時覆寫 .NET 8 WinForms 的初始 DPI 快取，並以 `finally` 還原；不變更 Windows 顯示設定。涵蓋 100%、125%、150%、200% 的初始視窗／搜尋列／圖示欄寬與輸入框邊界，以及模擬 DPI 訊息的往返切換。此 fixture 依賴 WinForms 私有欄位，升級 runtime 時若欄位變動須同步調整。

回歸確認：移除修正後，初始 192 DPI 時視窗仍是 580×289、搜尋列仍是 26 像素，測試失敗；加回修正後分別為 1160×578 與 52 像素，測試通過。這不是實體 2880×1920／200% 驗收的替代品；仍需在該設定下從頭啟動、開啟管理視窗，確認左右搜尋文字與圖示完整，並於不同縮放螢幕間移動後重開視窗檢查。
